# Proyec_Final_Ionic

Proyecto final de la materia Programación VI.

- **Alumno:** Isaias Almiron
- **Carrera:** Ingeniería Informática, 4to año, 8vo semestre, turno noche
- **Tema:** Cotizador de monedas
- **Stack:** Ionic 9 + Angular 22 + Capacitor

## Estado

Proyecto base generado con la plantilla `tabs`. Todavía no tiene las
pantallas del cotizador implementadas.

## Cómo ejecutar

```bash
npm install
ionic serve
```

Abre en `http://localhost:8100`.

## Build de producción

```bash
npm run build
```

El resultado queda en `www/`.

## Estructura

```text
src/
├── app/
│   ├── tabs/       Barra de pestañas
│   ├── tab1/       Primera pestaña
│   ├── tab2/       Segunda pestaña
│   └── tab3/       Tercera pestaña
├── environments/   Configuración por ambiente
└── assets/         Archivos estáticos
```
